# 学生工作区

**这份目录在导师包内是“学生种子模板”，不是可运行的学生个体**（见 `SEED.json`）：它没有运行工具、安装清单与当前状态，直接对它运行 `tools/check.py` 或导出入口会被拒绝并给出提示。先由导师用 `research/tools/first_student.py` 装配，或安装一个已导出的学生孢子包。

从 `START.md` 开始。这里的偏好、方法、身份与历史属于学生本人；导师只通过 `public/` 收到学生明确提交的内容，不读取 `personal/`。

学生可以按当前用户要求调整继承来的内容；导出学生孢子时读取自己的 `INHERITANCE.json`，只携带选中内容与该 profile 的运行资源，不预填个人身份、当前任务状态或个人记录。

可复用的改进先写成实际文件（方法、偏好或资源），再登记进清单。导师采用时只会从 `public/` 取件；是否被采用不影响你自己的版本，你可以继续保留自己的路线。
